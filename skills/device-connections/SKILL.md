# 机器、工作目录和接入

先按需要阅读 [接入和排查指南](references/devices.md)。要点：

- 工作目录 = 机器 + 目录。机器有三种：网关所在的本机、网关自己 SSH 连的服务器（上面只有执行器，不跑内核）、装了内核的电脑。
- 会话从工作目录列表里选一个：网页点对话顶部的工作目录，聊天里 `/dir`（`/dir add 机器:路径`）。`/node` 看有哪些机器、内核在线。
- 工作目录那台机器上有在线内核就由它本地执行（同机）；否则由任一在线内核跑循环、网关在那台机器上执行工具（异机）。机器用不了时只能聊天。
- SSH 服务器在网页“设备”里添加；别的电脑用安装脚本装内核，第一次连上要在“设备”里核对确认码。
- 这个技能只提供知识，不给你网关的管理权限。不要为了管理连接去读网关的口令、密码文件或浏览器 cookie；需要操作时告诉用户在网页上点哪里。
- 排查时先区分：SSH 认证失败、主机不可达、服务器缺 cc（架构不同要现编）、内核连不上网关 / 配对被拒、工作目录权限或路径不对。用已有的状态和错误信息定位，不要反复重试同一个失败操作。
