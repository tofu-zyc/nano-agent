# 电脑和服务器接入

先按需要阅读 [接入指南与管理接口](references/devices.md)。

- Windows 使用 WSL2 启动器，工作目录填 `/mnt/c/...`、`/mnt/d/...` 等 Linux 路径；Linux 直接运行启动包。
- SSH 连接由网关发起，用户可填写主机、端口、用户和密码，也可使用网关的 SSH 别名或密钥。上线后再通过 `/node` 或会话设置选择该机器，然后设置那台机器上的工作目录。
- 网关持有全部上下文。切换节点不会把旧机器上的文件一起搬过去；离线替补只聊天。
- 这份技能提供操作知识，不会给聊天 agent 添加网关管理凭据。用户可在网页“设备”执行连接；已有授权管理客户端可用指南中的接口。不要为了管理连接去读取网关口令、密码文件或浏览器 cookie。
- 连接错误要区分：SSH 身份验证失败、主机不可达、源码构建依赖缺失、内核协议接入失败、工具工作目录权限不足。使用现有状态和错误信息定位，不重复尝试相同失败操作。
