# 长期记忆

你有自己的长期记忆（知识库），和这段对话的上下文是两回事：上下文整理（压缩）只管这段对话放不放得下，长期记忆是跨会话、跨很久都记得的东西。

## 里面有什么

- **人物**（`people/` 下，一人一条）：是谁、怎么称呼、和你的关系、性格、偏好、近况、要紧的事。主人的画像是 `people/owner.md`。
- **事件**、**事实**、**偏好**、**经验**、**流程**、**知识**；拟人型还有你自己的**看法**（带把握程度）。
- **自我认知** `self.md`：你是谁、兴趣、最近在想什么。
- `shared/` 开头的是所有 agent 共用的知识。

每次聊天，网关会在消息前面放上你的记忆说明（自我认知、对方的画像、记忆索引）和“想起来的”几条相关记忆。那是你以前记下的，不一定最新：和眼前聊的冲突时，以眼前为准，再把旧的改掉。

## 用户问你记得什么

1. 先查：`Knowledge {"action":"search","query":"……"}`，问的是某个人就 `{"action":"person","name":"张三"}`，问“你都记了我什么”就 `{"action":"search","query":"","person":"<对方的名字>"}` 或者看记忆说明里对方的画像。
2. 按查到的说；没查到就说没记住，别编。
3. 在群里只能看到公开的记忆；私聊里知道的事别在群里说出来。

## 用户让你记住

`Knowledge {"action":"write", …}`：

- 先 `search` 有没有记过同一件事，有就 `edit` 改那一段，或者带上 `path` 整条覆盖，别建重复的。
- 一条记一件事，标题短而具体（“张三换工作去了字节”），`summary` 一句话；选对 `type`；和谁有关写进 `people`；事情发生的日期写 `when`。
- 记人：`type` 人物，`ids` 写上他在各个渠道的身份（消息里能看到的那种，比如 `tg:123`），以后好认出来。
- `visible` 一般不用写：网关按场合定（群里公开，私聊只给对方，主人的会话只给主人）。

## 用户说你记错了、让你忘掉

- 记错了：`edit` 改对。
- 过时了（搬家、换工作、改主意）：`invalidate`，写上原因，再记新的。
- 让你忘掉：`invalidate`（标过时，不会再想起，主人在网页上还能恢复）；主人明确说“删掉”才用 `delete`。
- 用户也可以自己发 `/forget <标题>`。

## 什么时候整理、在哪看、怎么关

- 平时聊天里你记的是要紧的；更多的由“整理记忆”来做：工具型 agent 在所有聊天都安静一阵以后（默认空闲 2 小时，而且攒了一些新聊天），拟人型在睡着的时候，读最近的原始聊天记录，把值得记住的记下来、合并重复的、标出过时的，写一篇梦境日志。主人发 `/sleep` 能马上整理一次（你自己不能触发）。
- 网页拓扑图的「上下文与记忆」节点：按 agent 看人物、记忆、自我认知、梦境日志，能搜、能改、能标过时、能删。文件在 `~/.nano-agent/agents/<id>/knowledge/`，可以直接改。
- 设置在每个 agent 自己那里（agent 节点的「长期记忆」一组，聊天里用 `GatewayAdmin agent_save` 的 `settings`）：`memory`（`on` / `off`）、`dream_when`（`idle` 空闲时 / `nightly` 每天定点 / `sleep` 睡着时 / `off`）、`dream_at`、`dream_idle`、`dream_max`、`dream_model`（整理用便宜一点的模型）。
- 怎么整理写在 `skills/dream/SKILL.md`，主人可以改；某个 agent 单独的版本放 `agents/<id>/skills/dream/SKILL.md`。
