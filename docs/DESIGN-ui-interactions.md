# 设计稿：界面细节操作

状态：**已实现（2026-10-22）**  
最后更新：2026-10-22  
相关：[HANDOFF.md](HANDOFF.md)、[DESIGN-model-node.md](DESIGN-model-node.md)、[DESIGN-topology-config.md](DESIGN-topology-config.md)（v0.4：拓扑图就是控制台）

这份文档只约束“点一下、按一下会发生什么”，避免拓扑图、设置面板和弹层之间互相抢操作。

## 1. 浮层怎么关

| 浮层 | 关闭方式 |
| --- | --- |
| 右键菜单 | 点菜单项、点菜单外空白、Esc、窗口失焦、窗口尺寸变化 |
| 目录选择器 / 工作目录选择器 | 点遮罩、取消/关闭按钮、Esc |
| 实时活动面板 | 再点底部状态条、Esc |
| 命令面板（Ctrl/⌘ K） | 点遮罩、执行任一项、Esc |
| 人格编辑器、SSH 服务器表单、定时任务表单 | 点遮罩、关闭/取消按钮、Esc（人格有没保存的修改时先问） |
| 聊天里的命令提示 | 继续输入、选一项、Esc |

- **Esc 按层关闭**：命令提示 → 右键菜单 / 目录选择器 / 实时活动 / 弹出的编辑器和表单 → 命令面板 → 右侧节点面板。上层关掉后，Esc 不应该顺手把下层也关掉。
- 输入法正在选字时，Esc 只取消候选，不关任何面板。
- 右键菜单打开时，画布不接收拖动和滚轮缩放；点空白的第一下只关菜单，不会触发下面的节点或画布。

## 2. 右侧节点面板

- 面板永远显示“当前选中的对象”。切换对象时从顶部开始，不保留上一个对象的“正在读取 / 已经删掉”状态。
- **会话设置跟随会话**：面板开着会话设置时，在会话列表、浏览器前进后退、⌘K 里切换会话，面板跟着换成当前会话。
- 离开会话列表、回到“会话”首页（没有选中会话）、删除当前会话时，面板收起。
- 面板开在模型、机器、工作目录等其他对象上时，切换会话不改变它。
- 删除对象后，面板显示明确的“已经删掉了”，不继续展示旧数据。

## 3. 会话里的草稿

- 每个会话各自保留没发出去的草稿（文字和已上传图片），切换会话不串台，切回来还在。
- 发送过程中切到别的会话，旧请求的结果不会清掉新会话的输入框；旧的历史请求也不能覆盖新会话的消息列表。
- 切换会话时，挂载工作目录的弹窗收起。

## 4. 拓扑画布

- 左键点节点 = 查看/配置；右键点节点 = 节点操作；右键空白 = 画布菜单。
- 画布上的按钮、统计、提示、图例不是空白：右键不弹画布菜单，双击不触发“适应窗口”。
- 拖动节点后松手的那一次 click 不误开节点；从空白开始拖动不会关闭已经打开的面板。
- “适应窗口”只在第一次布局和用户主动点击时发生；打开/关闭右侧面板不改变画布的缩放和位置。
- 画布菜单的标题是“画布”，不叫“新建”（里面还有“适应窗口”）。

## 5. 文案和行为一致

- 菜单、命令面板里的文案必须和实际动作一致。比如“测试默认模型”就真的发一次很小的模型请求，而不是只打开设置面板。
- “双击空白处适应窗口”不写成“复位”，避免被理解成重置节点位置。

## 6. 验收

浏览器里逐项检查：右键菜单点空白关闭、Esc 只关当前层、会话设置跟随切换、会话草稿不串台、目录选择器 Esc、命令面板和实时活动面板 Esc、画布按钮右键/双击不误触，并确认没有 JS 异常。
